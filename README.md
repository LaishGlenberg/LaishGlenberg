## Site

The active site is a React/Vite app served via GitHub Pages. The visual theme is defined in `src/index.css`. The root static files (`index-static.html`, `styles.css`, `script.js`) are legacy and will be removed in a separate cleanup.

- **genuinely useful**
  - [exa-cli](https://github.com/LaishGlenberg/exa-cli): exa web search cli for agents (ports exa's web mcp to typescript cli)
    - **npm**: [@lglen/exa-cli](https://www.npmjs.com/package/@lglen/exa-cli)
  - [pi-sudo-helper](https://github.com/LaishGlenberg/pi-sudo-helper): pi extension for enabling `sudo` command
  - [pi-command-cli](https://github.com/LaishGlenberg/pi-command-cli): a cli tool for making pi startup command more streamlined + the ability to save command profiles
    - **npm**: [@lglen/pi-command-cli](https://www.npmjs.com/package/@lglen/pi-command-cli)
  - [awk-changelog-tool](https://github.com/LaishGlenberg/awk-changelog-tool): npx cli tool that generates git changelogs extremely fast with built in gh cli integration for pr descriptions (lowkey broken rn lol)
    - **npm**: [@lglen/awk-changelog-tool](https://www.npmjs.com/package/@lglen/awk-changelog-tool)
  - [bing-image-helper](https://github.com/LaishGlenberg/bing-image-helper): node js sdk for interacting with internal bing image api used for agent grounding (not for prod use)
    - **npm**: [@lglen/bing-image-helper](https://www.npmjs.com/package/@lglen/bing-image-helper)
  - [find-open-seats-python](https://github.com/LaishGlenberg/find-open-seats-python): python script that hooks into ASU class search api catalog and uses ntfy to send notifications (built to run on raspberry pi)
 
- **useful but WIP, DEP or MISC**
  - [keep-cache-alive](https://github.com/LaishGlenberg/keep-cache-alive): vscode extension for enabling "loop" behavior in github copilot gui sidebar (probably not necessary any more)
  - [firebase-emulator-mcp](https://github.com/LaishGlenberg/firebase-emulator-mcp): node js mcp server for firebase emulators
    - **npm**: [@lglen/firebase-emulator-mcp](https://www.npmjs.com/package/@lglen/firebase-emulator-mcp)
  - [split-image-to-pdf](https://github.com/LaishGlenberg/split-image-to-pdf): a cli tool for splitting images into pdfs (meh)
  - [arrowhead-scaler-figma-plugin](https://github.com/LaishGlenberg/arrowhead-scaler-figma-plugin): figma plugin for better arrow head scaling, worked well only for certain arrows.
  - [termai](https://github.com/LaishGlenberg/termai): cli/tui that keeps track of command output for in terminal agent context. Hope to finish this one someday.
  - [image-moment-react-site](https://github.com/LaishGlenberg/image-moment-react-site): website for showing off image moment properties
  - [leetcode-solution-API](https://github.com/LaishGlenberg/leetcode-solution-API): unofficial leetcode answer api
  - [Datvis_Matrix_Tool](https://github.com/LaishGlenberg/Datvis_Matrix_Tool): website for teaching matrix operations and linear algebra interactively
  - [neural-net-builder](https://github.com/LaishGlenberg/neural-net-builder): website for building neural networks and training them interactively
  - [rate-my-professor-vs-experience-python-ML](https://github.com/LaishGlenberg/rate-my-professor-vs-experience-python-ML): stub linking to my 3 ipynb notebooks detailing lengthy ML report comparing teaching experience to rate my professor score
